# Smart Hospital Management System

## About the Project
Smart Hospital Management System is a C++ based project made to manage some common activities of a hospital in a simple and organized way. The system will deal with patient records, doctor and staff details, appointments, waiting queues, emergency cases, medical records, bed availability and billing.
The main purpose of this project is to reduce the manual work in hospital management and make it easier to store, search and manage important information.

## Main Features
- Patient record management
- Doctor and staff record management
- Appointment management
- Waiting queue management
- Emergency patient handling
- Bed availability management
- Medical record management
- Billing
- Searching and sorting of records
- File handling for storing data

## Technology Used
- C++
- Data Structures and Algorithms
- Object-Oriented Programming
- STL
- File Handling

## Data Structures Used
The project uses different data structures according to the requirements of different modules:
- Arrays
- Structures
- Linked Lists
- Queues
- Priority Queues
- Stack
- Trees
- Graphs

## Project Approach
The project follows a menu-driven approach. Different modules are used for managing patients, doctors, staff, appointments, emergency cases, beds, medical records and billing.
C++ concepts like classes, objects, inheritance, encapsulation and polymorphism are used in the project. Searching and sorting are used to manage records, while queues and priority queues are used for appointments and emergency cases.
File handling is also used so that the stored information is not lost when the program is closed.

## Project Goal
The main goal of this project is to make hospital operations more organized and reduce the amount of manual work required. At the same time, the project helps us understand how Data Structures, Algorithms and C++ concepts can be used in a practical project.
